# Todo-список

Небольшое приложение для списка задач на чистом HTML, CSS и JavaScript — без фреймворков и сборки.

## Возможности

- добавление задачи (кнопка «Добавить» или Enter);
- отметка задачи выполненной (клик по кружку или по тексту);
- удаление задачи (кнопка «×»);
- счётчик оставшихся задач;
- сохранение списка в `localStorage` — задачи не пропадают после перезагрузки страницы;
- адаптивный дизайн для телефона и поддержка тёмной темы системы.

## Структура

```
index.html   — разметка страницы
style.css    — стили
script.js    — логика приложения
```

## Как открыть

Самый простой способ — открыть файл `index.html` двойным кликом в любом современном браузере.

Или запустить локальный сервер из папки проекта, например:

```bash
python3 -m http.server 8000
```

и открыть в браузере http://localhost:8000.

> Задачи хранятся в `localStorage` конкретного браузера, поэтому в другом браузере или в режиме инкогнито список будет пустым.
